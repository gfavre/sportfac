We accept files extracted from LAGAPEO. They should be in .xlsx format and have the mandatory columns named like this:

  • "Nom": last name of the teacher
  • "Prénom": first name of the teacher
  • "Maîtrises" or "Années": classes the teacher is responsible for (e.g. "7S1,7S2"). Teachers without any class in this column are skipped.

Additional non-mandatory columns can be imported:

  • "Numéro SPEV" or "ID LAGAPEO": unique ID of the teacher, used to update an existing teacher on a new import. Without it, matching is done on first and last name.
  • "Courriel 1": email address of the teacher
